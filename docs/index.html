CHINESE INGREDIENT API · v0.1.0

从一份可信的食材数据开始。

为中国菜谱提供稳定 ID、中文名、别名、分类和来源。首版仅有少量人工核验的食材种子，不含调味品，不宣称覆盖完整。

图标与描述暂为空。许可证、来源和数据版本见 数据元信息 与 来源目录。

接口

  • GET /v1/ingredients：食材列表，默认 20 条。
  • GET /v1/ingredients?q=番茄：搜索规范名与显式收录的别名。
  • GET /v1/ingredients/{id}：单条食材。
  • GET /v1/categories：分类。
  • GET /v1/sources：来源和第三方许可。
  • GET /v1/meta：版本、数量和校验和。
  • OpenAPI 3.1 规范：可供客户端生成与接口导入。

筛选与分页

列表支持 q、category、limit（1–100）、offset（0–1000000）。category 的有效值以分类接口为准。未知或重复参数返回 400；不存在的 ID 返回 404。无搜索时按稳定 ID 排序；有搜索时依次按规范名精确、别名精确、规范名前缀、别名前缀、规范名包含、别名包含排序，再按 ID 排序。

curl --get 'http://127.0.0.1:8000/v1/ingredients' \
  --data-urlencode 'q=番茄' --data-urlencode 'limit=10'

离线下载

食材 JSON · 食材 CSV · 分类 JSON · 来源 JSON

JSON 与服务启动时载入的文件逐字节相同。CSV 中 aliases、sourceRefs、description、icon 使用 JSON 字符串保存，避免嵌套信息丢失。UTF-8，无 BOM。

边界

本地开发服务器默认仅监听 127.0.0.1。无鉴权、无写接口、无运行时抓取，不是生产部署方案。搜索只覆盖已收录别名，不做自动繁简转换、拼音、营养推断或模糊纠错。
